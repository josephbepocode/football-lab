# Football Lab

**Live:** https://josephbepocode.github.io/football-lab/

A football analytics web app covering La Liga, Bundesliga, Serie A, Ligue 1, Eredivisie and Liga Portugal. It has league tables, team pages, player pages, percentile pizza charts, shot maps, form trends and player-vs-player comparison.

It's a static site: vanilla ES modules, [D3 v7](https://d3js.org) for every chart, and pre-built JSON. There's no framework, no backend and no tracking, and it's hosted on GitHub Pages.

## Features
- **League tables** for 2026/27 (in progress) and 2025/26 (final), with sortable columns, form strips, a points race and an attack-vs-defence scatter
- **Team pages** with rolling form, table position over time, points pace against the leader and the league average, and full results and fixtures
- **Event Lab** for each league: an expected table (xG, xGA, shot-simulated xPts, PPDA, field tilt), chance-quality and style scatters, a filterable league shot map and per-90 leaderboards
- **Lab team pages** with match-by-match xG bars, shot maps for and against, rolling npxG, points vs xPts, a team-style radar and the squad
- **Player pages** with a 16-metric percentile pizza, per-90 breakdown, shot map, cumulative goals vs xG, form trend and similar profiles
- **Compare**: overlaid radar, mirrored per-90 bars and side-by-side shot maps
- **Explorer**: scatter any two metrics across about 1,000 players
- **⌘K search** across leagues, teams and players. Responsive layout, honours `prefers-reduced-motion`

## New: near-live La Liga, Barça post-match, Clásico throwback, PNG export
- **Near-live La Liga**: `.github/workflows/refresh-results.yml` runs every 30 min Fri–Mon 10:00–23:59 UTC and hourly otherwise. It rebuilds the openfootball base, then `scripts/build_live.py` overlays finished scores, kick-off dates and goal scorers from ESPN's public scoreboard JSON (no key). Every page shows **Last updated**.
- **Optional football-data.org**: add a repository secret `FOOTBALL_DATA_TOKEN` (free tier: 12 competitions incl. La Liga, 10 calls/min, delayed scores). If present, the job uses it as a fallback for scores and adds a live top-scorers table. No key is ever stored in the repo.
- **Barça post-match** (`#/barca`): one page per finished league match with score, scorers and table impact (position/points before → after).
- **Clásico 2015** (`#/clasico-2015`): Real Madrid 0–4 Barcelona shot maps from StatsBomb Open Data (historical).
- **PNG export** on every chart, credited "Football Lab · bepojoseph.xyz" plus the data source.
- **Player involvement tables** on player pages and side by side on Compare (StatsBomb, historical).

## Data: what's real and what's demo
| Data | Source | Status |
|---|---|---|
| Fixtures, results, tables and form (2025/26 and 2026/27, all six leagues) | [openfootball/football.json](https://github.com/openfootball/football.json), CC0-1.0 | **Real** |
| La Liga 2026/27 latest scores, scorers | ESPN public scoreboard JSON (keyless, unofficial endpoint); optional football-data.org | **Real** |
| Shots, xG, xPts, PPDA, field tilt, player per-90s and percentiles: La Liga, Serie A and Ligue 1 2015/16, plus Bundesliga 2023/24 (Bayer Leverkusen's 34 matches) | [StatsBomb Open Data](https://github.com/statsbomb/open-data) | **Real** |
| Eredivisie and Liga Portugal player labs | Generated by `scripts/build_lab.py` (fixed seed, invented names) | **Demo**, badged "Demo data" everywhere |

The Event Lab seasons differ from the live-results seasons because StatsBomb only releases selected seasons openly. Every page states its season.

## Rebuilding the data
```bash
python3 scripts/build_results.py         # refresh openfootball results (also runs weekly via GitHub Actions)
# Event Lab (needs about 2.7 GB of StatsBomb raw JSON, cached locally; run from the directory holding m_*.json):
#   put the matches/*.json files next to statsbomb_extract.py, then
python3 scripts/statsbomb_extract.py     # per-match summaries -> sb/
SB_DIR=path/to/that/dir python3 scripts/build_lab.py   # aggregates, percentiles, demo data -> data/
```

## Method notes
- Minutes come from starting XIs, substitutions and red cards. A player's position group is the one where they logged the most minutes.
- Percentiles are per 90 against players in the same group with 900+ minutes, pooled across the four real datasets. Demo players are ranked against that pool but never added to it.
- xPts are computed exactly from each match's shot xGs, treating every shot as an independent chance.
- League tables break ties on points, then goal difference, then goals scored. Official head-to-head rules aren't applied.

Inspired by football-visual sites such as DataMB, but independent: it uses none of their code, images or data. There are no betting or odds features.
